# 字体回归截图中的社区“大肥鱼”角色

本目录的历史字体回归截图包含社区角色图像，用于 **非商业字体故障复现与回归记录**。原设计源已迁入 FDE2E Omni 的探索目录。这不是 FDE2E 自有角色，也不是 DeepSeek 官方形象。项目代码的许可证不覆盖此处图像，也不覆盖 `.desigma`、原型和截图中包含的角色图像。

- 原型「溟月」：B 站 [上善无形](https://space.bilibili.com/4456176)。
- DeepSeek 女仆鲸鱼娘改编：[ZipZipPipe](https://space.bilibili.com/4168597)。
- 动画制作及直接来源：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，固定修订 `60bb2eb4113eca92b2636ab906f8e6c9c934ae13`。
- 形象许可：[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)，署名、非商业、相同方式共享。[形象声明](https://www.bilibili.com/opus/1247156596114456581)。上游动画素材允许开源使用、禁止商用，衍生公开展示须附原作者 GitHub 地址。
- 发现素材时参考了 [Henry-GongZY/deepseek-waifu-codex-pet](https://github.com/Henry-GongZY/deepseek-waifu-codex-pet) 和 [TreapGoGo/deepseek-whale-girl](https://github.com/TreapGoGo/deepseek-whale-girl)；实际交付图片直接从上述原始动画提取。

改动仅包括抽取一帧、清除透明区域的编解码噪声和裁掉透明边缘，不重画人物。逐文件 URL、时间点、原始与输出 SHA-256 见 [Omni 探索稿来源记录](https://github.com/jixoai/fde2e-omni-v1/blob/main/docs/research/design-explorations/personal-agent-android/assets/whale-girl/provenance.json)；图像内也保留来源与许可元数据。图像改编沿用 CC BY-NC-SA 4.0。发布含该角色的设计研究时须保留上述署名和限制；商业产品上线须另行获得授权或替换为具有相应权利的角色。

当前是静态姿态预览，没有声线授权、Live2D 模型、口型同步或角色动画运行时。
